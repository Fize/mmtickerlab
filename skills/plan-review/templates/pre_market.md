# 盘前计划模板（输出规范）

> AI 分析指南：按模块顺序执行。**关键原则**：快照数据看当日，趋势数据看周期，牛熊/震荡等大判断必须使用最少一个月的数据。

---

## 数据分类：快照 vs 趋势

| 判断内容 | 数据类型 | 最小窗口 | 获取方式 |
|:---|:---|:---|:---|
| 当日涨跌、涨停数、成交额 | 快照 | 1 天 | `overview.py` / `limit_up.py` |
| 牛熊/震荡格局 | 趋势 | **1 个月（4周）** | `stock_profile.py --period weekly --days 8` |
| 量能趋势（放量/缩量/地量） | 趋势 | **10 个交易日** | `stock_profile.py --period daily --days 30` |
| 涨停数趋势（情绪升降） | 趋势 | **5 个交易日** | `limit_up.py --date YYYYMMDD`×5 |
| 资金流向持续性 | 趋势 | **5 个交易日** | `fund_flow.py --period 5` |
| 个股技术形态 | 趋势 | **6 个月（250 日）** | `stock_profile.py --mode technical` |
| 题材持续性 | 趋势 | **3 个交易日** | 模块二+模块三交叉对比 |

## 模块一：宏观定调（趋势+快照）

### 快照数据 — 昨日收盘状态

```bash
skills/market/.venv/bin/python skills/market/scripts/overview.py
```

提取：上证/深证/创业板 最新价+涨跌幅、沪深300/上证50 涨跌幅、上涨家数占比、涨停/跌停数、两市成交额。

### 趋势数据 — 指数格局判断

对上证指数、创业板指分别执行（**最少 4 周周线**）：

```bash
skills/market/.venv/bin/python skills/market/scripts/stock_profile.py 000001 --mode kline --period weekly --days 8
skills/market/.venv/bin/python skills/market/scripts/stock_profile.py 399006 --mode kline --period weekly --days 8
```

提取：最近 4-8 周的周线 OHLC。观察：
- 连续几周收阳/收阴？
- 每周高低点是在抬高还是在降低？
- 最新周线处于近 4 周区间的高位/中位/低位？

### 趋势数据 — 量能趋势

对上证指数执行日线（**最少 30 日**）：

```bash
skills/market/.venv/bin/python skills/market/scripts/stock_profile.py 000001 --mode kline --period daily --days 30
```

提取：最近 30 日每日成交额。计算：
- 5 日均量 vs 20 日均量：5 日线在上 = 短期放量，在下 = 短期缩量
- 当前量 vs 30 日最高量：是否接近地量或天量？

### 趋势数据 — 外围参考

通过 WebFetch 获取财联社或东方财富全球行情页：
- A50 期货当月连续：昨收 + 近期走势方向
- 美股 DJIA/SPX/NDX：前日收盘 + 近一周涨跌趋势

### 趋势数据 — 汇率

USD/CNY 在岸汇率，观察最近 2 周的变动方向。

### 消息面

```bash
skills/market/.venv/bin/python skills/market/scripts/news.py 000001 --n 10
```

筛选涉及央行、证监会、国务院、美联储、关税、PMI 关键词的新闻。

### 判断规则

**牛熊格局**（基于周线 4-8 周趋势）：

| 条件 | 判断 |
|:---|:---|
| 近 4 周 3 周收阳，每周高低点逐步抬高，站上 MA60（日线） | **上升趋势（偏牛）** |
| 近 4 周 2 阳 2 阴，高点不创新高、低点不创新低 | **震荡格局** |
| 近 4 周 3 周收阴，每周高低点逐步降低，跌破 MA60 | **下降趋势（偏熊）** |
| 量能持续萎缩，波幅收窄 | **窄幅整理，方向选择在即** |

### 输出格式

```
### 宏观定调

#### 趋势格局（基于 x 周周线）

- 上证指数：近 4 周 [x阳x阴]，高点 [抬高/持平/降低]，低点 [抬高/持平/降低]，**趋势判断：[上升/震荡/下降]**
- 创业板指：近 4 周 [x阳x阴]，[同上]
- 量能趋势：5 日均量 xxx 亿 / 20 日均量 xxx 亿，[放量/缩量/持平]，量价 [配合/背离]
- 整体格局：**[牛/熊/震荡/方向选择]**

#### 昨日快照

- 上证 xxx.xx (+x.xx%) / 深证 xxx.xx (+x.xx%) / 创业板 xxx.xx (+x.xx%)
- 沪深300 +x.xx% / 上证50 +x.xx%
- 上涨 x,xxx 家 (xx.x%) / 成交 x,xxx 亿

#### 外围环境

- A50 昨收 xxx.xx ([涨/跌]x.xx%)，近一周 [偏多/偏空/震荡]
- 美股 DJIA [涨/跌]x.xx%、SPX [涨/跌]x.xx%、NDX [涨/跌]x.xx%
- USD/CNY = x.xxxx，近 2 周 [升值/贬值/稳定]
- 今日预期：[高开/平开/低开]概率偏大

#### 消息面

- [来自 news.py 的具体标题+时间，或"消息面平静"]
```

## 模块二：市场情绪（快照+趋势）

### 快照数据

```bash
skills/market/.venv/bin/python skills/market/scripts/limit_up.py
skills/market/.venv/bin/python skills/market/scripts/fund_flow.py --type concept
skills/market/.venv/bin/python skills/market/scripts/fund_flow.py --type industry
```

提取：涨停总数、Top 15 涨停股列表（代码、名称、连板数、行业、换手率、封板资金）、概念/行业 Top 5 净流入。

### 趋势数据 — 涨停数趋势

连续 5 天运行涨停查询，观察涨停数的变化方向：

```bash
for d in [今日-4天, 今日-3天, 今日-2天, 昨日, 今日]; do
  skills/market/.venv/bin/python skills/market/scripts/limit_up.py --date $d | grep "Total Limit-Up"
done
```

### 趋势数据 — 资金流向趋势

```bash
skills/market/.venv/bin/python skills/market/scripts/fund_flow.py --type concept --period 5
skills/market/.venv/bin/python skills/market/scripts/fund_flow.py --type industry --period 5
```

### 判断规则

**涨停趋势方向**：

| 近 5 天涨停数变化 | 判断 |
|:---|:---|
| 连续 3 天以上增加 | 情绪升温（↑） |
| 连续 3 天以上减少 | 情绪降温（↓） |
| 在窄区间波动（±20 家以内） | 情绪稳定（→） |
| 单日暴增 50%+ 后次日回落 | 情绪脉冲，需确认持续性 |

**情绪定性**（快照+趋势综合）：

| 昨日涨停 | 趋势方向 | 最终判断 |
|:---|:---|:---|
| ≥ 80 | ↑ | 强修复，情绪加速 |
| ≥ 80 | → | 强势延续 |
| ≥ 80 | ↓ | 过热后降温，注意分歧 |
| 40-79 | ↑ | 弱转强 |
| 40-79 | → | 正常 |
| 40-79 | ↓ | 正常转冷 |
| 20-39 | ↑ | 初冰回暖 |
| 20-39 | → | 偏冷 |
| 20-39 | ↓ | 加速降温 |
| < 20 | — | 冰冷 |

### 输出格式

```
### 市场情绪

#### 趋势回顾

- 近 5 日涨停数：xx → xx → xx → xx → xx（[趋势方向]）
- 近 5 日资金流向：概念 Top1 [板块名] 5 日净流入 xx.xx 亿 / 行业 Top1 [板块名] 5 日净流入 xx.xx 亿

#### 昨日快照

- 涨跌分布：上涨 x,xxx (xx.x%) / 下跌 x,xxx (xx.x%)，涨停 xx 家 / 跌停 x 家
- 成交额 x,xxx 亿（对比 5 日均量：+x%/-x%）

#### 涨停结构

| 行业 | 涨停家数 | 代表股 |
|:---|:---|:---|
| xx | xx | xx(xxx)、xx(xxx) |
| ... | ... | ... |

- 连板高度：最高 x 板（xxx），阶梯 [完整/断层]
- 首板 xx 家 / 2板 xx 家 / 3板 xx 家 / 4板+ xx 家

#### 情绪结论

- **定性：[强修复 / 强势延续 / 正常 / 偏冷 / 冰冷]**，趋势方向 [↑升温 /→稳定 / ↓降温]
- **资金聚焦**：概念 Top 3 — xx(+x.xx亿)、xx(+x.xx亿)、xx(+x.xx亿)
- **资金聚焦**：行业 Top 3 — xx(+x.xx亿)、xx(+x.xx亿)、xx(+x.xx亿)
```

## 模块三：焦点题材

### 数据来源

模块一消息面 + 模块二资金方向 + 模块二涨停集中行业 + 5 日资金趋势（`fund_flow.py --period 5`）。

### 题材评估标准（多日交叉验证）

| 验证维度 | 信号强度 | 权重 |
|:---|:---|:---|
| 模块二涨停集中行业 Top 3 | 有重叠 = +1 | 40% |
| 模块二概念资金今日净流入 Top 3 | 有重叠 = +1 | 20% |
| 5 日资金趋势（`fund_flow.py --period 5`）连续流入 | 有 = +1 | 20% |
| 模块一新闻中有利好催化 | 有 = +1 | 10% |
| 连板阶梯完整，有 ≥3 板龙头 | 有 = +1 | 10% |

**评分 ≥ 3/5 → 主线 | 评分 2/5 → 次主线 | 评分 1/5 → 观察 | 评分 0/5 → 不列入**

### 持续性判断

- 5 日资金趋势为该板块连续 3 天以上净流入 → 持续性较高
- 板块内涨停数在增加（对比昨日+前日）→ 发酵中
- 板块内涨停数在减少 → 分歧或退潮

### 输出格式

```
### 焦点题材

1. **xx题材**（主线，综合评分 4/5）
   - 涨停集中度：涨停 x 家，板块涨幅 +x.xx%
   - 资金信号：今日净流入 +x.xx 亿，5 日净流入 +x.xx 亿（连续 x 天流入）
   - 消息催化：[来自 news.py 的相关新闻标题]
   - 核心龙头：xx（xxx，x板）
   - 持续性：[高/中/低]，理由：[涨停数趋势/5日资金方向]

2. **xx题材**（次主线，评分 2/5）
   - ...

3. **xx题材**（观察，评分 1/5）
   - ...
```

无评分 ≥ 2 的题材时，输出"**暂无明显主线，等待方向选择**"。

## 模块四：自选股交易预案

### 趋势数据 — 长期技术背景

每只自选股执行（**最少 6 个月日线，获取完整均线**）：

```bash
skills/market/.venv/bin/python skills/market/scripts/stock_profile.py {code} --mode technical --days 10
```

> `--mode technical` 内部基于 500 日历日（约 250 交易日）计算指标，输出最近 10 天。

提取四个表格数据：趋势均线 / MACD&Boll / 震荡指标 / 波动率成交量。

### 趋势位置判断（基于 SMA_60 和 SMA_250）

| 条件 | 判断 |
|:---|:---|
| Close > SMA_60 > SMA_250，且均线多头排列 | **长期上升趋势** |
| Close > SMA_60，SMA_60 > SMA_250，但短期均线缠绕 | **中期偏多，短期震荡** |
| SMA_250 附近 (±5%) 波动，SMA_60 与 SMA_250 粘合 | **横盘整理** |
| Close < SMA_60 < SMA_250，均线空头排列 | **长期下降趋势** |
| Close 在 SMA_60 和 SMA_250 之间震荡 | **方向选择** |

### 技术形态识别（结合长期背景）

在长期背景下，检查最近 3 天数据：

1. **多头排列延续买点**：长期上升趋势 + 短期回踩 SMA_20 附近 + KDJ_J < 30（优质低吸点）
2. **平台突破**：横盘整理 1 个月以上 + 放量突破 BOLL_UP + RSI_6 50-70
3. **MACD 零轴金叉**：长期震荡或偏多 + MACD 柱从负转正 + DIF 上穿 DEA
4. **超跌反弹**：长期趋势不破 + RSI_6 < 20 + KDJ_J < 0 + 远离 MA60 > 20%
5. **W 底/双底**：前期低点 + 二次回踩不破新低 + 放量收阳

**以下形态在长期下降趋势中应标注"高风险逆势交易"警告**。

### 输出格式

```
### {股票名称}（{代码}）

- **长期区间**：[上升趋势 / 偏多震荡 / 横盘整理 / 方向选择 / 下降趋势（⚠️）]
- **技术形态**：[形态名称] — [信号描述]
- **技术快照**：
  | 指标 | 数值 | 指标 | 数值 |
  |:---|:---|:---|:---|
  | 收盘 | xx.xx | MA5/10/20 | xx.xx/x.xx/xx.xx |
  | MA60 | xx.xx | MA250 | xx.xx |
  | BOLL 上/中/下 | xx/x/xx | RSI(6) | xx.x |
  | MACD DIF/DEA | xx/xx | KDJ J | xx.x |
  | ATR(14) | x.xx | 量比 | x.x |
- **入场条件**：竞价 [条件]，盘中 [价位 + 确认信号]
- **仓位**：[x]%（根据模块五温度），[分批/一次性]
- **目标**：第一目标 xx.xx（理由：[前高/BOLL上轨/压力位]），第二目标 xx.xx
- **止损**：xx.xx（理由：[SMA_20/前低/ATR×2]），放弃条件：[描述]
- **[如为下降趋势，添加 ⚠️ 高风险逆势交易]**：[警告内容]
```

无信号标的：

```
### {股票名称}（{代码}） — 无信号

长期区间：[趋势判断]，当前 [简要技术状态：如"SMA_5 下穿 SMA_20，MACD 绿柱扩大"]
```

## 模块五：仓位纪律

### 市场温度（快照+趋势综合）

| 昨日涨停 | 趋势方向 | 跌停数 | 温度 | 仓位上限 | 操作策略 |
|:---|:---|:---|:---|:---|:---|
| ≥ 80 | ↑ 或 → | < 10 | 🔥 微暖 | 70% | 积极操作，分仓参与 |
| ≥ 40 | ↑ 或 → | < 30 | ☀️ 正常 | 50% | 适度参与，严格止损 |
| ≥ 80 | ↓ | < 30 | 🔥→🌥 转冷 | 30% | 高位降温，减仓为主 |
| ≥ 20 | ↑ 或 → | < 50 | 🌥 偏冷 | 20% | 控仓参与，尾盘低吸 |
| < 20 | — | ≥ 50 或 — | ❄️ 冰冷 | 10% | 减仓观望为主 |
| 数据缺失 | — | — | ⚠️ 未知 | 10%（防御） | 任何数据不足时默认为极低仓位，非交易时段默认冰冷 |

### 禁止行为清单

- **始终禁止**：追涨开盘拉升 3%+、交易计划外品种、亏损加仓摊平成本、单票超过仓位上限
- **冰冷/偏冷**：≤1 笔/日、优先尾盘决策（14:30 后）、不追高只低吸
- **正常/微暖**：单票 ≤ 30% 总仓位、每笔必带止损、允许分批建仓

### 输出格式

```
### 仓位纪律

- 市场温度：**[温度标签]**（昨日涨停 xx 家，趋势 [↑→↓]）
- 建议仓位上限：**x%**
- 今日禁止行为：
  - [根据温度列出]
```
