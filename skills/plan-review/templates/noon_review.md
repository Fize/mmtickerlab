# 午间复盘模板（输出规范）

> AI 分析指南：中午 11:30 后执行。核心目标：检查上午走势是否偏离计划，调整下午策略。
>
> 午间复盘以**盘中快照数据**为主（最新的实时数据），但需与盘前计划的趋势判断做对比（"计划预期了什么，实际发生了什么"）。

---

## 模块结构

```
# ☀️ A股午间复盘 YYYY-MM-DD

1. 上午盘面快照
2. 资金风口与异动
3. 计划标的跟踪对齐
4. 下午操作策略
```

---

## 模块一：上午盘面快照

### 数据获取

```bash
skills/market/.venv/bin/python skills/market/scripts/overview.py
skills/market/.venv/bin/python skills/market/scripts/limit_up.py
```

### 提取数据

| 来源 | 提取字段 | 用途 |
|:---|:---|:---|
| `overview.py` | 上证/深证/创业板 最新价+涨跌幅 | 早盘指数走势 |
| `overview.py` | 上涨/下跌/平盘家数 | 早盘赚钱效应 |
| `overview.py` | 成交额 | 半日量能 |
| `limit_up.py` | 涨停总数 | 早盘情绪热度 |
| `limit_up.py` | 涨停股列表（代码、名称、连板、行业、换手率、炸板次数） | 连板接力+炸板率 |
| `limit_up.py` | 炸板次数>0 股票数 | 计算炸板率 |

### 对比基准

读取盘前报告（`report/YYYYMMDD_盘前计划.md`）模块一中的趋势判断，将上午实际表现与预期对比：

| 盘前趋势判断 | 上午实际 | 含义 |
|:---|:---|:---|
| 上升趋势 | 上午收红 | 符合预期，趋势延续 |
| 上升趋势 | 上午收绿 > 1% | 趋势中意外回调，需警惕 |
| 震荡格局 | 上午方向性不强 | 符合震荡预期，下午可能延续 |
| 震荡格局 | 上午单边涨/跌 | 可能为突破/破位信号 |
| 下降趋势 | 上午收绿 | 符合弱势预期 |
| 下降趋势 | 上午收红 > 1.5% | 可能为超跌反弹，关注持续性 |

### 量能估算

- 半日成交 v.s. 昨日全天成交
- 如果上午量 = 昨日全天的 55%+ → 今天放量
- 如果上午量 = 昨日全天的 35%-55% → 正常
- 如果上午量 = 昨日全天的 35% 以下 → 今天缩量

### 炸板率

```
炸板率 = 炸板次数 > 0 的涨停股数 / 涨停总数 × 100%
```

| 炸板率 | 判断 |
|:---|:---|
| < 20% | 封板坚定，做多信心强 |
| 20%-40% | 正常分歧 |
| > 40% | 多空分歧大，注意风险 |

### 输出格式

```
### 上午盘面快照

#### 指数

| 指数 | 最新价 | 涨跌幅 | 盘前预期 | 匹配度 |
|:---|:---|:---|:---|:---|
| 上证 | xxx.xx | +x.xx% | [预期内容] | ✅/⚠️ |
| 深证 | xxx.xx | +x.xx% | — | — |
| 创业板 | xxx.xx | +x.xx% | — | — |

#### 涨跌结构

- 上涨 x,xxx / 下跌 x,xxx / 平盘 xxx
- 涨停 **xx** 家 / 跌停 **x** 家 / 炸板率 **xx%**
- 半日成交 x,xxx 亿（占昨日全天 xx%，预估全天 [放量/正常/缩量]）

#### 早盘定性

- [强势 / 偏强 / 震荡 / 偏弱 / 弱势]
- [与盘前预期对比的简要判断]
```

## 模块二：资金风口与异动

### 数据获取

```bash
skills/market/.venv/bin/python skills/market/scripts/fund_flow.py --type concept
skills/market/.venv/bin/python skills/market/scripts/fund_flow.py --type bigdeal
```

### 对比基准

读取盘前报告模块三的焦点题材列表，将上午资金方向与之对比：

| 盘前焦点题材 | 上午资金表现 | 含义 |
|:---|:---|:---|
| 主线 | 上午资金继续流入，领涨板块与之重合 | ✅ 主线确认，下午可持续关注 |
| 主线 | 上午资金方向与盘前不同 | ⚠️ 轮动出现，需重新评估 |
| 次主线/观察 | 上午异军突起，资金大量流入 | 可能升格为主线，关注 |

### 输出格式

```
### 资金风口

#### 领涨板块 Top 5

| 板块 | 净流入(亿) | 涨幅 | 领涨股 | 与盘前焦点是否一致 |
|:---|:---|:---|:---|:---|
| xx | +x.xx | +x.xx% | xx | ✅/⚠️ |
| ... | ... | ... | ... | ... |

#### 大单异动

| 时间 | 股票 | 成交价 | 金额(万) | 性质 | 涨跌幅 |
|:---|:---|:---|:---|:---|:---|
| xx:xx | xx(xxx) | xx.xx | x,xxx | 买盘/卖盘 | +x.xx% |

无显著大单则写"上午暂无明显异常大单成交"。

#### 与盘前焦点对比结论

- [一句总结：资金是否按预期方向走？有轮动吗？]
```

## 模块三：计划标的跟踪对齐

### 数据获取

1. 读取 `report/YYYYMMDD_盘前计划.md` 模块四，提取所有标的代码
2. 对每只执行：

```bash
skills/market/.venv/bin/python skills/market/scripts/stock_profile.py {code} --mode realtime
```

提取：名称、最新价、涨跌幅、涨跌额、今开、昨收、最高、最低、成交量、成交额。

### 与计划对比

读取盘前计划中每只标的的"入场条件"和"止损价位"，逐只检查：

| 上午情况 | 操作建议 |
|:---|:---|
| 已达到入场价位且信号确认 | "已触发，[是否已执行/下午如何跟进]" |
| 接近入场价位（差 < 1%）但未到位 | "接近触发，下午持续关注" |
| 远未触达入场价位 | "条件未满足，继续等待" |
| 跌破止损价位 | "⚠️ 已触发止损条件，建议放弃该标的" |
| 逆势大涨/大跌（涨幅偏离预期 > 5%） | "异常波动，需重新评估" |

### 状态标签

| 涨跌幅范围 | 标签 |
|:---|:---|
| ≥ 9.5% | 🟢 涨停 |
| 3% – 9.5% | 🟢 强势 |
| 0% – 3% | 🟡 微涨 |
| -3% – 0% | 🟡 微跌 |
| -3% – -9.5% | 🔴 走弱 |
| ≤ -9.5% | 🔴 跌停 |

### 输出格式

```
### 计划标的跟踪

| 标的 | 现价 | 涨跌幅 | 最高/最低 | 状态 | 计划执行 |
|:---|:---|:---|:---|:---|:---|
| xx(xxx) | xx.xx | +x.xx% | xx/x | 🟢 | 已突破入场价 xx.xx，[是否已执行] |
| xx(xxx) | xx.xx | +x.xx% | xx/x | 🟡 | 距入场价 xx.xx 还差 x%，继续等 |
| xx(xxx) | xx.xx | -x.xx% | xx/x | 🔴 | ⚠️ 逼近止损 xx.xx，差 x%，准备放弃 |
```

如无计划标的或计划今日为空仓，写"今日盘前计划无交易标的，跳过此模块"。
```

## 模块四：下午操作策略

### 数据来源

模块一（指数+情绪）+ 模块二（资金方向）+ 模块三（计划对齐结果）。

### 策略推导规则

| 上午条件 | 下午策略 | 风控提醒 |
|:---|:---|:---|
| 涨停 ≥ 80 且 炸板率 < 30% | 可积极参与，关注新发酵方向 | 防范高位分歧，不追缩量涨停 |
| 涨停 ≥ 50 且 炸板率 ≤ 50% | 适度参与，尾盘低吸试错 | 尾盘（14:30 后）确认再出手 |
| 涨停 ≥ 50 且 炸板率 > 50% | 分歧加剧，只做最强辨识度 | 回避中位股，炸板率高预示下午分歧扩大 |
| 涨停 < 50 且 上涨占比 < 50% | 控仓，尾盘低吸 | 弱势不反弹加仓 |
| 涨停 < 20 且 跌停 > 20 | 减仓观望，不开新仓 | 警惕下午加速退潮 |

### 与盘前仓位纪律对比

读取盘前报告模块五的仓位建议，上午情况是否有变化？

| 盘前温度 | 上午实际 | 是否调整 |
|:---|:---|:---|
| 偏暖/正常 | 盘中出现跌停 > 20 | ⚠️ 下调仓位至偏冷/冰冷 |
| 偏冷 | 盘中涨停 > 80，持续升温 | 可上调一档 |

### 输出格式

```
### 下午策略

#### 策略基调

- [一句话，如"分歧加剧，控仓为主"]
- 下午重点关注：[方向/标的]

#### 仓位调整

- 盘前建议 x% → 上午实际后建议 [不变/上调至x%/下调至x%]
- 理由：[一句解释]

#### 操作建议

- [对标的一的操作建议]
- [对标的三的操作建议]
- ...
```
