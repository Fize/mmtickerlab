# Strategy Definition

## 目标

研究当日首次涨停形成的资金合力是否可能在下一交易日获得溢价。策略周期为 T 日形成并执行入场决定，T+1 日按预先定义的条件退出或管理仓位。

该策略不是长期估值、趋势波段、连板接力，也不是预测股票次日精确涨幅。

## 决策顺序

严格按照以下顺序分析：

1. 首板策略近期是否存在赚钱效应；
2. 市场是否存在显著系统性风险；
3. 当日是否存在可辨识的主线或板块共振；
4. 候选是否确为当日首板且具备可交易性；
5. 候选在板块中的地位和辨识度；
6. 上板、开板、回封和换手过程；
7. 次日潜在收益是否覆盖失败情形与费用；
8. 是否应该交易以及如何分配风险。

## 市场环境门禁

优先观察近几个交易日昨日首板在次日的开盘、最高、收盘或策略实际退出收益，并结合涨停家数、炸板率、跌停家数、失败股反馈、市场宽度、成交额、指数状态和主线集中度。

不要使用单一指标划分市场。证据冲突时标记为 `MIXED`；无法计算首板次日表现时标记为 `INSUFFICIENT_EVIDENCE`，不得把缺失值解释为零。

只有 `FAVORABLE` 或经过明确降仓处理的 `MIXED` 环境允许产生 `BUY`。`UNFAVORABLE` 必须输出 `NO_TRADE`。

## 可证伪原则

每个交易理由至少对应一个次日可验证结果。例如：

- “板块前排”对应次日相对板块表现；
- “分歧转一致”对应回封后封板稳定性和次日承接；
- “近期首板赚钱效应改善”对应预先定义样本的次日收益统计。

不能被次日数据验证的故事不得作为主要入场理由。

## 研究身份边界

把公开交易方法视为策略灵感，而非权威事实。所有阈值、时间窗口和权重都应带版本，并通过模拟交易样本验证。不要声称该策略等同或忠实复刻特定交易者。
